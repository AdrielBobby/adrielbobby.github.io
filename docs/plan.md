# Portfolio rebuild plan

Status: still planning. Nothing is built until the design brief is approved.

## Decided so far
- **Content inventory** (`content-inventory.md`): projects, resume, LinkedIn posts, GitHub repos compared and reconciled.
- **Direction:** mostly 2D technical-editorial site, dark and light sections used for different content modes, technical credibility first, personality second. Projects feel like case files; the site stays easy to read. Style reference for motion and palette switching: Death Scroll (not Sunny's Journey: no storytelling or timeline walk).
- **Type:** Young Serif (headlines, one weight, no italic), Manrope (body, nav, buttons), JetBrains Mono (metadata labels). All open-licensed per web sources; license files still to be read.
- **Palette:** graphite + patina green (`#0f1211` / `#1a1f1d` / `#e7e9e6`, green `#4fb08a` on dark and `#337058` on light). Project accents rebuilt as a matched set.
- **Skill tree:** the tech stack and skills (65 nodes, six branches), shown as game-style icon tiles on branch lines, click for detail. Security tools are "learned", not tied to projects. Real logos where they exist (37 of 65), custom-drawn glyphs for the other 28 (approved, including the redrawn Hydra and Netcat). Removed for lack of evidence: Prisma, Next.js, pfSense, Ubuntu Server, C++. C and Java stay as coursework; Tor, Steghide and Stegseek stay as learned tools; Docker is mapped to MedLedger and the Cyberdome internship (Bharat Gas is left off because it is private).
- **Logo:** two marks. The **kv mark** is the solid notched tile with kv cut out (Young Serif letters), used top-centre in the nav and as the favicon. The **logo** is the hand-drawn face, version B (cleaned face, original brush strokes, recoloured). Final SVG and favicon files are made at build time (text converted to outlines). The old purple gradient goes.
- **Opening sequence (approved, prototype: `hero-sketch.html`):** the page loads on the kv tile (Young Serif kv). Scrolling grows the green tile until the page is green. Near 20% the serif kv hands over to stroke letters; the k becomes an X eye, the v bends into the tongue, the second eye splits off. Your own brush strokes then paint on, the tongue fills like liquid, and the page blends from green to white. No black stage. Scroll is eased every frame so it never looks choppy. Reduced motion shows the finished logo. Death Scroll does this kind of thing with hand-authored Rive animations; we keep code-driven SVG and can revisit Rive.

5. **Motion rules (PROPOSED, desktop only, awaiting Adriel's reaction):**
   - **Principle:** motion carries meaning (where you are, what changed, what just opened). Nothing moves just to move. Three kinds only: scroll-linked (follows the scroll position), triggered (plays once when something arrives), and hover or focus (small, instant feedback).
   - **Timing tokens:** hover and focus 150 ms; small state changes (nav pill, tile detail) 250 to 400 ms; scene entrances 500 to 700 ms; scroll-linked motion has no duration, it follows the scroll. Entering uses one ease-out curve, `cubic-bezier(.2,.8,.2,1)`; no bounce or overshoot anywhere.
   - **Scroll feel:** one global eased scroll (the page glides to the scroll position, factor about 0.12, as in the approved opening). It never hijacks scroll speed or direction; scenes use sticky pinning, not scroll-jacking. Off under reduced motion.
   - **By scene:** opening (scroll-linked, approved); Who I am (portrait resolves from noise as the section arrives, scroll-linked); Projects (the page colour eases to each project's accent as you reach it, about 500 ms; the tile or row lifts 4 px on hover); Skills (tile detail opens in 250 ms; branch lines draw in once on arrival); Experience (rows fade up once, 60 ms stagger, 500 ms); Contact (halftone dissolve to black, scroll-linked; terminal types itself in once, cursor blinks only there); Nav (pill opens in 420 ms, approved); Case files (scroll-spy highlight only, no entrance animation beyond a 300 ms fade-in of the page).
   - **Never animates:** body text, anything that shifts layout while you read, looping or auto-playing motion (the only loop is the terminal cursor), parallax on text, anything flashing more than three times a second, sound.
   - **Reduced motion:** the opening shows the finished logo; the portrait appears complete; accent colours change instantly; the dissolve becomes a straight cut to dark; the terminal prints instantly and the cursor stops blinking; the nav opens without a transition; eased scroll is off.
   - **Skip and repeat visits:** a "Skip intro" link in the opening jumps to Who I am with the page already pale grey. There is no loader: the old terminal loader and pixel grid are removed, and the first screen is the kv tile at once. Nothing is gated on repeat visits.
   - **Performance:** animate only transform and opacity, plus canvas for the portrait and dissolve; draw the canvases only while their progress is changing and pause them off screen; no heavy libraries for simple motion; target a steady 60 fps on a normal laptop.
   - **Decided:** the opening stays at about 5.6 screens (Adriel: keep as is; the skip link covers impatient visitors).
   - **Decided:** home page to case file is a plain cut for now; revisit once built. Phones are deferred.
6. **Technical decisions (PROPOSED, desktop only):**
   - **Stack:** keep React 18 + Vite and GitHub Pages, deployed with `gh-pages` as now. Add `react-router-dom` for the five pages. Drop `three`, `postprocessing`, `react-github-calendar` and probably `framer-motion` (CSS transitions, one scroll hook and two canvases cover every motion rule). That removes the heaviest chunks.
   - **Routing on GitHub Pages:** it has no server rewrites, so a direct visit to `/projects/thaalam` would 404. Fix: the standard `404.html` redirect trick (404 page redirects to `/` and the router restores the path). Hash URLs (`/#/projects/thaalam`) are the fallback but look worse and break section anchors.
   - **Scroll and sections:** one small scroll hook (eased 0.12) drives the opening, portrait and dissolve; the nav's active section comes from IntersectionObserver. Returning from a case file restores the projects scroll position.
   - **Icons:** bundle the logos locally from Simple Icons (37 logos as inline SVG, 28 hand-made glyphs), no CDN calls, so the page works offline and leaks nothing. Footer line: logos are trademarks of their owners, used only to name tools I have used.
   - **Fonts:** self-host Young Serif, Manrope and JetBrains Mono (woff2, Latin subset, `font-display: swap`) instead of Google Fonts, after checking each licence file (all three are OFL; keep the licence text in the repo).
   - **Images:** the four case files use the project photo for Thaalam and generated type or screenshots for the rest. WebP, sized to display width, lazy-loaded below the fold. Portrait is code (canvas grid JSON, about the size of a small image), not a photo.
   - **Resume:** `public/Resume.pdf` with a stable name, replacing `Resume_v3.pdf` (Adriel supplies the new file). Opens in a new tab.
   - **Metadata:** title, description, Open Graph and Twitter card image (the kv tile on graphite), `theme-color`, favicon from the notched kv tile (SVG plus a PNG fallback), per-page titles for the case files, `robots.txt` and a sitemap.
   - **Privacy:** no analytics, no cookies, no third-party requests. Private-project details (Thangan) stay as writing only; `docs/content-inventory.md` is never published.
   - **Performance budget:** first load under about 150 KB of JS gzipped, LCP under 1.5 s on a normal connection, no layout shift, canvases lazy-started when near the viewport.
   - **Accessibility:** real headings and landmarks, skip link, visible focus, 4.5:1 contrast on every accent, canvas portrait and dissolve get text alternatives, reduced-motion rules as in item 5.
   - **Testing before launch:** build and preview, Lighthouse, keyboard-only pass, reduced-motion pass, check every link and the 404 redirect on the real GitHub Pages URL.
