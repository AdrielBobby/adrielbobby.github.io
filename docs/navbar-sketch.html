The kv pill, collapsed and expanded

Fixed at the top centre of every page. Collapsed it is just the kv mark in a small pill. Expanded it opens outward from the mark: About, Projects, Skills on the left, Experience, Contact and Resume on the right. Desktop only for now.

1. The two states on each surface

Collapsed
Expanded (Projects active)

2. Try it

Hover or focus the kv mark. Click it to pin open.

3. How it behaves

  • At the very top of the page (the opening animation) only the kv mark shows, so the animation stays clean.
  • After the opening it opens when you hover or tab to the mark, and closes when you leave. Click pins it open, click again closes it.
  • The active section gets the surface's accent colour and a small dot. It updates as you scroll.
  • Colour follows the scene: dark pill on graphite and green, light pill on pale grey, mark always the site green.
  • Resume is the only outlined item, because it opens a PDF instead of scrolling.
  • Case file pages use the same pill, with "Projects" marked active and a back link beside it.
  • Accessibility: the mark is a button with an expanded state, links are real links, the open animation is switched off for reduced motion.

The pill borrows the notched tile from the logo page, so the favicon, the opening tile and the nav all read as one mark.
