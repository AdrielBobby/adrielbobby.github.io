Skill tree

The tech stack as icon tiles on branch lines. Pick a branch, then click a tile to see where a skill was used. A solid border means learned to use; a dashed border means learning now. Tools with a recognised logo show that logo; the rest show a custom glyph. Everything is tinted in the branch colour so nothing fights the palette. Security tools carry no project mapping.
